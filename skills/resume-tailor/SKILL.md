# resume-tailor

本文件是本仓库的中文收录入口。[上游原版](upstream/SKILL.md)与许可证保存在 `upstream/`，固定版本及本地说明见 [SOURCE.md](SOURCE.md)。

## 用途与输入

对照目标岗位调整简历摘要、技能顺序和经历表述，生成适合该岗位的版本，并记录修改理由。

- 适用场景：已有完整简历，需要针对不同岗位调整重点；检查哪些经历与目标岗位相关。
- 所需输入：现有简历、目标岗位的职位描述；可提供已有岗位分析结果、输出语言与格式要求。
- 使用示例：请用 resume-tailor 对照这份职位描述修改我的中文简历，逐条说明修改理由，保留真实经历和已有指标。

## 使用步骤

1. 阅读[上游主 Skill](upstream/SKILL.md)，按其中的岗位分析、简历检查和分项调整流程执行。
2. 先确认岗位职责、技能要求和优先级。上游先调用 `job-description-analyzer`；已有分析结果时直接使用，缺少时可由当前 Agent 根据职位描述完成分析。
3. 对照原简历调整摘要、技能顺序和经历重点，保留事实、日期、职位名称及指标，并记录修改理由。

## 依赖与限制

主要依赖语言模型，无随附脚本或额外 Python、Node.js 运行依赖。上游提及的配套 `job-description-analyzer` 未在本次收录，可使用已有分析结果或由当前 Agent 先完成岗位分析。

原版要求保留 ATS（Applicant Tracking Systems，招聘系统）可读取的简历格式；本 Skill 提供内容调整规则，未附带 DOCX/PDF 排版、导出或招聘系统匹配验证工具。

本目录保存源码收录包；安装到 Agent 工具或运行完整流程属于另行任务。

## 预期输出

针对岗位的简历调整方案或修改稿，包括摘要前后对照、技能顺序、经历修改及关键词说明。
