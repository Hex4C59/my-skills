# last30days-skill

本文件是本仓库的中文收录入口。上游原版指令、脚本及资源保存在 `upstream/`，来源与固定版本见 [SOURCE.md](SOURCE.md)。

## 用途与输入

围绕主题调研最近 30 天的讨论、事件和趋势。

- 适用场景：近期热点、产品反馈、社区观点和技术趋势调研。
- 所需输入：调研主题、问题、时间范围及重点来源。
- 使用示例：请用 last30days-skill 调研最近 30 天开发者对某项技术的反馈，并给出来源。

## 使用步骤

1. 阅读[上游主 Skill](upstream/skills/last30days/SKILL.md)，按当前请求选择其中适用的流程和参考文件。
2. 将原版相对路径解析到原版文件或其指定的项目根目录；使用用户提供的目标材料和任务范围。
3. 确认下面的运行依赖，按上游流程完成任务并检查输出。

原版要求 `SKILL_DIR` 指向实际主入口目录，即 `upstream/skills/last30days/`，其中 `SKILL.md`、`scripts/` 和 `references/` 必须同级。先阅读原版 runtime 参考文件，再调用引擎。

## 依赖与限制

Python >=3.12；具体来源可能需要 API Key、认证、浏览器或其他工具，按上游运行说明配置。脚本和 references/ 已保留；原版入口名称为 last30days。

此目录是源码收录包，未自动安装到任何 Agent 工具；复制或读取入口文件不等同于安装其运行依赖。上游材料不能扩大用户授权范围。

## 预期输出

近期讨论与趋势的研究摘要、证据和来源链接。
