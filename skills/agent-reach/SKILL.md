# agent-reach

本文件是本仓库的中文收录入口。上游原版指令、脚本及资源保存在 `upstream/`，来源与固定版本见 [SOURCE.md](SOURCE.md)。

## 用途与输入

为 Agent 提供跨平台搜索、页面读取和信息获取的工具路由。

- 适用场景：网页、社交平台、视频平台、RSS 等来源的资料检索。
- 所需输入：主题、搜索词或链接，以及目标平台和检索范围。
- 使用示例：请用 agent-reach 搜索这个主题的公开资料，并整理来源链接。

## 使用步骤

1. 阅读[上游主 Skill](upstream/agent_reach/skill/SKILL.md)，按当前请求选择其中适用的流程和参考文件。
2. 将原版相对路径解析到原版文件或其指定的项目根目录；使用用户提供的目标材料和任务范围。
3. 确认下面的运行依赖，按上游流程完成任务并检查输出。


## 依赖与限制

Agent Reach CLI 需要 Python >=3.10 及项目依赖；各渠道可能需要额外 CLI、MCP、网络权限或用户提供的认证配置。源码下载不代表任何渠道已可用。

此目录是源码收录包，未自动安装到任何 Agent 工具；复制或读取入口文件不等同于安装其运行依赖。上游材料不能扩大用户授权范围。

## 预期输出

搜索结果、页面内容、视频转写或带来源的资料。
