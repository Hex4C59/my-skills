# git-commit

本文件是本仓库的中文收录入口。[上游原版](upstream/SKILL.md)与许可证保存在 `upstream/`，固定版本及安装来源见 [SOURCE.md](SOURCE.md)。

## 用途与输入

根据 Git diff 判断提交类型、范围和摘要，生成提交信息；用户要求提交时，可按任务范围组织暂存文件并执行提交。

- 适用场景：编写 Git commit message、检查暂存变更、组织逻辑一致的提交。
- 所需输入：已初始化的目标 Git 仓库、工作区或暂存区改动，以及用户对提交范围、语言和格式的要求。
- 使用示例：`$git-commit 分析当前改动，先生成中文提交信息供我审查。`

## 使用步骤

1. 阅读[上游主 Skill](upstream/SKILL.md)，确认用户请求的范围是生成信息还是实际提交。
2. 在用户指定的目标 Git 仓库中检查状态与 diff，根据实际改动生成提交信息。
3. 按用户要求审查输出；仅在任务授权包含实际提交时执行对应 Git 操作。

## 依赖与限制

需要 Git CLI 和已初始化的目标仓库；无额外 Python 或 Node.js 运行依赖。原版支持暂存与执行提交，安装或读取 Skill 本身不代表用户已要求提交。

本仓库的 `COMMIT_CONVENTION.md` 当前为待审查草案；实际使用时按用户已确认的规范和当前任务要求输出。

## 预期输出

符合指定格式的提交标题、可选正文和页脚；如果任务包含实际提交，另报告提交哈希与变更范围。
