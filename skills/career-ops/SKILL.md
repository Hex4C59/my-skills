# career-ops

本文件是本仓库的中文收录入口。上游原版指令、脚本及资源保存在 `upstream/`，来源与固定版本见 [SOURCE.md](SOURCE.md)。

## 用途与输入

组织求职工作流，支持岗位检索、职位评估、简历定制和申请进度管理。

- 适用场景：准备简历、评估职位匹配度、跟踪申请和准备面试。
- 所需输入：简历、职业资料、目标岗位或职位描述；实际使用时再配置个人档案。
- 使用示例：请用 career-ops 对照我的简历评估这份职位描述，列出匹配点和差距。

## 使用步骤

1. 阅读[上游主 Skill](upstream/.agents/skills/career-ops/SKILL.md)，按当前请求选择其中适用的流程和参考文件。
2. 将原版相对路径解析到原版文件或其指定的项目根目录；使用用户提供的目标材料和任务范围。
3. 确认下面的运行依赖，按上游流程完成任务并检查输出。

原版 `PROJECT_ROOT` 应解析为 `upstream/`（同时包含 `AGENTS.md` 和 `modes/`）。求职目标材料由用户另行提供；目录中的上游示例不代表用户个人资料。

## 依赖与限制

package.json 声明 Node.js ^22.13.0 或 >=23.4.0；按功能需要浏览器、模型服务配置及 PDF/LaTeX 等工具。路由依赖 modes/、config/ 和脚本，均已保留。

此目录是源码收录包，未自动安装到任何 Agent 工具；复制或读取入口文件不等同于安装其运行依赖。上游材料不能扩大用户授权范围。

## 预期输出

岗位评估、定制简历、求职材料、申请记录或面试准备内容。
