# writing-for-agents

本文件是本仓库的中文收录入口。[上游主 Skill](upstream/SKILL.md)、配套参考和界面元数据保存在 `upstream/`，来源与固定提交见 [SOURCE.md](SOURCE.md)。

## 用途与输入

编写或审查 Agent 使用的指令文档，检查规则是否明确、资料引用何时触发、信息放置是否合适，以及任务完成标准能否判断。

- 适用场景：编写或整理 `AGENTS.md`、`CLAUDE.md`、`SKILL.md`，审查重复、过时或含糊的规则，以及调整配套文档的组织方式。
- 所需输入：目标文档或仓库、希望改善的问题、必须保留的规则；按任务需要提供现有参考文件。
- 使用示例：`$writing-for-agents 审查当前 AGENTS.md 的表达和结构，先列出修改建议供我审查。`

## 使用步骤

1. 阅读[上游主 Skill](upstream/SKILL.md)，结合用户指定的目标文档和范围检查内容。
2. 编写或修改 Skill 时，再读取 [SKILL-MECHANICS.md](upstream/SKILL-MECHANICS.md)，并按目标宿主实际支持的格式处理元数据与调用方式。
3. 按用户请求给出审查意见或修改文档，核对原有规则是否保留、引用是否有效，以及完成标准是否明确。

## 依赖与限制

本 Skill 为文档指令及参考文件，无额外 Python、Node.js 或服务依赖。上游主指令和参考文件以英文为主；文档语言按当前任务要求处理。

原版关于 Skill 调用机制的说明需要结合目标工具使用，不能直接作为所有宿主都支持同一字段的依据。整理文档时保留用户已明确规定的约束和授权范围。

## 预期输出

文档审查意见、修改建议，或按用户要求完成的指令文档；必要时包括配套文件调整和引用检查结果。
