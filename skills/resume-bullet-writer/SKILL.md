# resume-bullet-writer

本文件是本仓库的中文收录入口。[上游原版](upstream/SKILL.md)与许可证保存在 `upstream/`，固定版本及本地说明见 [SOURCE.md](SOURCE.md)。

## 用途与输入

逐条修改简历中的工作和项目经历，把笼统的职责描述写成具体行动、贡献与成果，并说明修改理由。

- 适用场景：经历描述过于笼统；需要突出个人贡献、明确项目规模或压缩条目长度。
- 所需输入：现有简历条目、实际工作或项目细节、已有成果指标；可提供目标岗位、输出语言和格式要求。
- 使用示例：请用 resume-bullet-writer 润色我的中文项目经历，逐条给出原文、修改稿和修改理由，保留真实数据。

## 使用步骤

1. 阅读[上游主 Skill](upstream/SKILL.md)，按其中的条目检查、信息补充和改写流程执行。
2. 从用户材料确认个人行动、项目规模和结果，再选择合适的表达；按需补问影响改写的经历细节。
3. 调整动词、顺序和长度，交付原文与修改稿的对照、修改理由及待补充材料。

## 依赖与限制

主要依赖语言模型，无随附脚本或额外 Python、Node.js 运行依赖。本 Skill 提供简历内容改写规则，未附带 DOCX/PDF 排版和导出工具。

原版要求每条经历至少包含一个数字，并提供估算方法。实际使用时区分已确认指标与待核实估计；估计需标明并经用户核实，缺少依据的成果列为待补充。示例中的数字不能作为用户的实际成果。

本目录保存源码收录包；安装到 Agent 工具或运行完整流程属于另行任务。

## 预期输出

简历条目的修改稿、原文对照、修改理由，以及需要补充或核实的指标与经历细节。
